# English interview repair workbook

Six original manual practice modules for candidates who want to explain their experience more clearly in English. Each module includes a goal, explicitly fictional worked example, failure contrast, ten-minute pair drill, temporary fillable worksheet, and self-check criteria.

Published by the MakeInterview/MockLive team; manual practice only. The separate live AI interview service is currently paused.

## Use offline

Download the HTML files and `style.css` together. Open `index.html` in any current browser. No installation, account, server, JavaScript, analytics, or runtime dependency is required. Optional related reading links need internet access.

Choose a module, rehearse with a partner using true non-confidential experience, type short notes in the worksheet, and use the browser Print command if desired. Worksheet notes are temporary: the workbook does not store or send them. Copy important notes before reloading or closing. Keep notes within the visible boxes when printing.

## Modules

1. `clarify-the-question.html`: clarify ambiguous questions.
2. `ownership-and-teamwork.html`: distinguish personal ownership from a team outcome.
3. `quantities-without-invention.html`: explain numbers and missing measurements honestly.
4. `plain-english-tradeoffs.html`: explain a technical decision and its accepted cost.
5. `uncertainty-and-verification.html`: identify a knowledge gap and a useful check.
6. `close-and-invite.html`: finish an answer and leave space for a relevant follow-up.

The numerical examples and scenarios are invented teaching material, not customer data or product results. Practice is not a language certification or a promise of a hiring outcome.
